# Этап 2 — Капча при вступлении

## Реализованный контур

```text
Новый участник supergroup
  → Telegram chat_member update
  → капча включена? (глобальный профиль или индивидуальный)
  → restrictChatMember (mute) + сообщение с кнопкой «Я не бот»
  → callback_query от того же telegram_user_id
  → снятие ограничения, аудит CAPTCHA_PASSED
```

После успешной проверки сообщение с кнопкой удаляется из чата, а подтверждение
(«✅ Проверка пройдена, добро пожаловать!») показывается всплывающим окном только
тому, кто прошёл капчу — Telegram не даёт отправить сообщение в чат видимым лишь
одному участнику, поэтому это единственный способ сделать подтверждение приватным.

## Настройка

Раздел «Модерация» — глобальная политика по умолчанию для чатов с наследованием.
Страница чата (`/chats/[id]`) — включение, таймаут (1–1440 мин) и действие при провале
(исключить с возможностью вернуться / заблокировать без возврата) для конкретного чата,
либо переключение на глобальный профиль — по той же схеме, что уже используется для
правил автомодерации и Anti-Raid.

## Честные ограничения этапа

- Работает только для supergroup (Telegram API не позволяет `restrictChatMember` в обычных группах).
- Кнопку может нажать только пользователь с тем же Telegram ID, что и приглашённый участник — Telegram
  доставляет `callback_query` любому, кто видит сообщение, поэтому проверка на совпадение ID обязательна.
- Таймаут проверяется той же ежедневной cron-задачей (`/api/cron/moderation-expirations`), что уже снимает
  истёкшие временные mute. Это значит, что автоматическое исключение непрошедших капчу может произойти
  с задержкой до 24 часов, а не точно по истечении заданного таймаута. Настоящий real-time контроль
  потребует более частого cron-триггера (доступно на платных планах Vercel) — сознательно не стали делать
  это предпосылкой запуска функции.
- Если Anti-Raid уже ограничил того же нового участника в этом же событии (режим «Mute новых участников»),
  капча не перезаписывает это ограничение — участник остаётся под защитой Anti-Raid до её истечения.
- Бот не имитирует прохождение капчи и не создаёт fake-события: запись в журнале появляется только при
  реальном нажатии кнопки или реальном срабатывании таймаута.
